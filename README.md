# 아기 앨범

엄마가 화면 안내대로 찍은 짧은 영상으로, 18개월 전후 아기가 직접 반응하며 노는 웹앱입니다.

바로 쓰기: https://kabunia12-a11y.github.io/baby-album/

## 놀이 3가지

| 놀이 | 아기가 하는 것 | 엄마 영상의 반응 |
| --- | --- | --- |
| 까꿍 놀이 | 화면 터치, 소리 | 가린 얼굴로 기다리다가 바로 "까꿍!" |
| 따라 해 봐 | 몸짓(카메라), 터치 | 몸짓을 보여 주고 기다리다가 칭찬 |
| 이야기 주고받기 | 옹알이(마이크), 터치 | 묻고 듣는 얼굴로 기다리다가 대답 |

- 촬영은 앱 안에서 놀이마다 약 1분. 단계마다 짧은 조각으로 따로 녹화해서, 놀이 중 반응이 지연 없이 바로 시작됩니다.
- 아기 차례에는 화면 테두리가 반짝입니다. 같은 행동에는 늘 같은 반응이 나와서, 아기가 원인과 결과를 알아채기 쉽습니다.
- 녹화, 얼굴·손 인식(MediaPipe Tasks Vision), 소리 감지는 모두 기기 안에서 처리하고, 영상은 브라우저(IndexedDB)에만 저장합니다.

## 구조

- `app/` — 배포되는 정적 웹앱 (GitHub Actions로 GitHub Pages에 배포)
  - `app.js` — 촬영 안내, 놀이 진행, 실시간 인식
  - `sw.js` — 오프라인 캐시 (앱 파일, 인식 모델)
- `baby-album.html` — 처음 만든 수동 질문 방식 프로토타입 (참고용)

## 로컬 실행

```bash
python -m http.server 8765 --directory app
```

카메라는 HTTPS 또는 localhost에서만 켜집니다.
